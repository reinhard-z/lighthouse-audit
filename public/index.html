Lighthouse Audit

Fresh website performance, accessibility, and SEO checks. No separate signup.

A remote MCP server that lets ChatGPT and other compatible MCP clients run a fresh Lighthouse lab audit of one public web page and explain the results.

MCP endpoint

https://audit.mrza.ch/mcp

Connect a client

  1. In an MCP client that supports remote servers over Streamable HTTP, add a server with the endpoint above. Select no authentication; the server needs no API key or login.
  2. In ChatGPT, custom MCP servers can be connected where developer mode is available to your account. A public directory listing for Lighthouse Audit does not exist.
  3. Ask for an audit of a public page. The client may ask you to approve the tool call.

“No separate signup” means you do not need an account, Google login, or API key for this service. Your MCP client may still require its own account or integration approval.

Example prompts

  • “Run a Lighthouse audit of https://mrza.ch on mobile.”
  • “Which performance, accessibility, or SEO issues should I investigate first?”
  • “I deployed a change. Run a fresh audit of https://mrza.ch and compare it with the previous result in this conversation.”

What you get

Each audit covers all four Lighthouse categories: performance, accessibility, best practices, and SEO. Results include category scores, lab metrics (LCP, FCP, CLS, TBT and Speed Index), and the most relevant findings with evidence.

Every request runs a new audit; nothing is cached or stored. One call audits one page on one device, mobile by default. An audit can take up to about a minute.

Limitations

  • Only public HTTP(S) pages can be audited; private, local, and logged-in pages cannot.
  • Submit only public URLs without confidential information. URLs with obvious credentials or tokens are refused, but this check cannot detect every secret.
  • One page per call; there are no whole-site crawls and no audit history.
  • Metrics are lab measurements from a single run, not real-user Core Web Vitals. Scores vary between runs, automated accessibility checks are not a complete assessment, and an SEO score is not a ranking guarantee.

Uses Lighthouse via Google PageSpeed Insights.
